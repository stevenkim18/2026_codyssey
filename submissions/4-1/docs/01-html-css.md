# HTML과 CSS 설명 자료

## 1. HTML의 역할

HTML은 페이지의 구조와 의미를 담당합니다. 브라우저가 어떤 콘텐츠가 제목이고, 어떤 영역이 내비게이션이며, 어떤 요소가 폼인지 이해하도록 작성합니다.

## 2. 시맨틱 HTML

`div`는 의미가 없는 일반 컨테이너입니다. 반면 시맨틱 태그는 콘텐츠의 역할을 이름으로 표현합니다.

- `header`: 페이지 또는 영역의 머리말
- `nav`: 주요 이동 메뉴
- `main`: 페이지의 핵심 콘텐츠
- `section`: 주제가 있는 콘텐츠 영역
- `article`: 독립적으로 의미가 있는 콘텐츠
- `footer`: 페이지 하단 정보

이 프로젝트에서는 `index.html`의 전체 구조에 시맨틱 태그를 사용했습니다. 시맨틱 HTML을 사용하면 코드의 의도를 읽기 쉽고, 검색 엔진과 스크린 리더 같은 보조 기술도 문서 구조를 이해하기 쉬워집니다.

## 3. 접근성을 고려한 HTML

- 프로필 이미지에 `alt="Steven Kim의 프로필 일러스트"`를 넣었습니다.
- 폼의 `label for`와 입력 요소의 `id`를 일치시켰습니다.
- 버튼에 `aria-label`, `aria-expanded`, `aria-pressed`를 사용했습니다.
- API 상태와 폼 성공 메시지에 `aria-live` 또는 `role="status"`를 사용했습니다.
- 키보드 사용자가 본문으로 바로 이동할 수 있도록 skip link를 넣었습니다.

## 4. CSS 변수

`css/style.css`의 `:root`에서 색상, 간격, 그림자, 반지름 등을 변수로 관리합니다.

```css
:root {
  --bg: #f4f1eb;
  --text: #18211d;
  --accent: #c6ed63;
}
```

다크 모드에서는 `[data-theme="dark"]`에 같은 변수 이름을 다른 값으로 다시 정의합니다.

```css
[data-theme="dark"] {
  --bg: #101613;
  --text: #eef4ec;
}
```

컴포넌트마다 색상 값을 반복하지 않아도 되고, 테마를 바꿀 때 변수 값만 바꾸면 페이지 전체가 함께 바뀐다는 장점이 있습니다.

## 5. Flexbox와 Grid

| 기준 | Flexbox | Grid |
| --- | --- | --- |
| 방향 | 한 방향 중심 | 행과 열을 함께 제어 |
| 사용 위치 | 네비게이션, 버튼 묶음 | 프로젝트 카드 목록, 전체 레이아웃 |
| 이 프로젝트의 이유 | 로고와 메뉴를 가로로 정렬 | 카드 개수에 따라 열 수를 자동 조정 |

네비게이션은 로고와 메뉴를 한 줄에 배치해야 하므로 Flexbox를 사용했습니다.

```css
.nav {
  display: flex;
  align-items: center;
  justify-content: space-between;
}
```

프로젝트 카드는 화면 폭에 따라 열의 수가 바뀌어야 하므로 Grid와 `auto-fit`, `minmax`를 사용했습니다.

```css
.projects-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
}
```

## 6. 반응형 디자인

모바일 퍼스트로 기본 스타일을 작성하고, 화면이 넓어질 때 미디어 쿼리로 레이아웃을 확장합니다.

- 767px 이하: 햄버거 메뉴, 한 열 레이아웃
- 768px 이상: 태블릿 레이아웃
- 1024px 이상: 데스크톱 간격과 섹션 크기 확대

모바일에서 메뉴를 숨기고 햄버거 버튼을 보이는 것은 CSS가 담당하고, 실제 열기·닫기 상태는 JavaScript가 `active` 클래스로 제어합니다.

## 7. 평가 질문

### CSS 변수의 장점은 무엇인가요?

색상과 간격을 한 곳에서 관리할 수 있어 유지보수가 쉽고, 다크 모드처럼 여러 요소의 스타일을 한 번에 바꾸기 좋습니다.

### Flexbox와 Grid를 어떻게 선택했나요?

한 방향으로 요소를 정렬하는 네비게이션은 Flexbox를, 카드처럼 행과 열을 함께 배치하는 영역은 Grid를 선택했습니다.

### 모바일 퍼스트란 무엇인가요?

작은 화면의 기본 스타일을 먼저 작성한 뒤, 미디어 쿼리로 태블릿과 데스크톱 스타일을 추가하는 방식입니다. 작은 화면에서 불필요한 스타일을 줄이고 점진적으로 확장할 수 있습니다.
